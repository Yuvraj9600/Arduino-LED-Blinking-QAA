# Arduino LED Blinking – QA Documentation

## Project Overview
This project demonstrates LED blinking using an Arduino Uno.

## Objective
To turn an LED ON and OFF at regular intervals using Arduino programming.

## Components Required
- Arduino Uno
- LED
- 220-ohm resistor
- Jumper wires

## Working
The LED turns ON for one second and OFF for one second continuously.

## Programming Language
C++ (Arduino)

## Quality Assurance
QA issues will be documented using GitHub Issues to identify problems, analyze root causes, and record solutions.
